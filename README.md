# 🍀 javascript-lotto-precourse
간단한 로또 발매기를 구현한다.

---
## 📝 구현 기능 목록

### 1. 로또 구입 금액 입력 받기
- [x] `구입금액을 입력해 주세요.` 출력
- [x] 잘못된 입력값일 경우 throw문을 통해 예외 발생

  - [예외] 입력값이 없을 경우 
  - [예외] 숫자가 아닌 값을 입력했을 경우 (문자, 기호)
  - [예외] 소수를 입력했을 경우 
  - [예외] 음수 또는 0을 입력했을 경우  
  - [예외] 공백이 있을 경우
  - [예외] 1,000원으로 나누어 떨어지지 않는 경우
<br>

> 테스트 목록
> - [x] 입력값이 1,000원 단위일 때 올바르게 저장되는가?
> - [x] 구입금액이 1,000원 단위가 아닐 때 예외가 발생한다.
> - [x] 입력값이 없을 시 예외가 발생한다.
> - [x] 숫자가 아닌 입력(문자, 기호) 시 예외가 발생한다.
> - [x] 소수 입력 시 예외가 발생한다.
> - [x] 음수 또는 0 입력 시 예외가 발생한다.
> - [x] 공백 입력 시 예외가 발생한다.
<br>

### 2. 발행한 로또 수량 출력하기
- [x] 발행한 로또 수량 구하기 (로또 구입 금액 / 1000)
- [x] `8개를 구매했습니다.` 출력
<br>

> 테스트 목록
> - [x] 구입금액에 따라 로또 수량이 올바르게 계산된다.
<br>

### 3. 발행한 로또 번호 출력하기
- [x] 로또 발행하기
      
  - 중복되지 않는 6개의 숫자 뽑기 (Random 값 추출은 `Random. pickUniqueNumbersInRange()` 활용)
  - 로또 번호는 오름차순으로 정렬
  - 발행한 로또 수량만큼 반복
<br>

> 테스트 목록
> - [x] 한 장의 로또 번호가 6개인지 확인한다.
> - [x] 6개의 번호 중 중복된 숫자가 없는지 확인한다.
> - [x] 6개의 번호가 오름차순으로 정렬되는지 확인한다.
> - [x] 모든 숫자가 1~45 범위인지 확인한다.
> - [x] 발행된 로또 수량이 구입 수량과 일치하는가?
<br>

### 4. 당첨 번호 입력 받기
- [x] `당첨 번호를 입력해 주세요.` 출력
- [x] 쉼표(,)를 기준으로 번호 구분하기
- [x] 잘못된 입력값일 경우 throw문을 통해 예외 발생        

  - [예외] 입력값이 없을 경우                                   
  - [예외] 공백이 있을 경우
  - [예외] 1 ~ 45 범위의 정수가 아닐 경우        
  - [예외] 중복되는 숫자가 있을 경우        
  - [예외] 6개가 아닐 경우 
<br>

> 테스트 목록
> - [x] 입력 문자열을 쉼표 기준으로 분리하여 숫자 배열로 변환하는지 확인한다.
> - [x] 입력값이 없을 시 예외가 발생한다.
> - [x] 문자, 기호, 소수 입력 시 예외가 발생한다. (*쉼표 제외)
> - [x] 공백 입력 시 예외가 발생한다.
> - [x] 1 ~ 45 범위를 벗어난 숫자 입력 시 예외가 발생한다.
> - [x] 중복된 숫자 입력 시 예외가 발생한다.
> - [x] 당첨 번호의 개수가 6개가 아닐 시 예외가 발생한다.
<br>

### 5. 보너스 번호 입력 받기
- [x] `보너스 번호를 입력해 주세요.` 출력
- [x] 잘못된 입력값일 경우 throw문을 통해 예외 발생        

  - [예외] 입력값이 없을 경우                
  - [예외] 숫자가 아닌 값을 입력했을 경우 (문자, 기호)        
  - [예외] 소수를 입력했을 경우        
  - [예외] 음수를 입력했을 경우        
  - [예외] 공백이 있을 경우
  - [예외] 1 ~ 45 범위의 숫자가 아닐 경우        
<br>

> 테스트 목록
> - [x] 유효한 숫자 입력 시 올바르게 저장되는지 확인한다.
> - [x] 입력값이 없을 시 예외가 발생한다.
> - [x] 숫자가 아닌 입력(문자, 기호) 시 예외가 발생한다.
> - [x] 소수 입력 시 예외가 발생한다.
> - [x] 공백 입력 시 예외가 발생한다.
> - [x] 1 ~ 45 범위를 벗어난 숫자 입력 시 예외가 발생한다.
<br>

### 6. 당첨 내역 출력하기
- [x] 사용자가 구매한 로또 번호와 당첨 번호 비교하기
- [x] 당첨 내역 출력하기
<br>

> 테스트 목록
> - [x] 각 로또 번호와 당첨 번호 일치 개수를 정확히 계산한다.
> - [x] 5개 번호 일치 + 보너스 번호 포함 시 2등으로 계산된다.
> - [x] 일치 개수에 따라 통계 객체가 올바르게 갱신된다.
<br>

### 7. 수익률 출력하기
- [x] 수익률 계산하기
  - 수익률(%) = (당첨 금액 / 구입 금액) x 100
  - 소수점 **둘째 자리에서 반올림**하여 **소수점 첫째 자리까지 표시**
  - 예시: `100.0%`, `51.5%`, `1,000,000.0%`
    
- [x] 수익률 출력하기
<br>

> 테스트 목록
> - [x] 수익률 계산이 정확하게 이루어지는지 확인한다.
> - [x] 소수점 둘째 자리에서 반올림하여 첫째 자리까지 표시되는지 확인한다.
> - [x] 여러 당첨금 합산 시에도 소수점 반올림이 올바르게 처리되는지 확인한다.
<br>
